# 学习记录技能

## 职责

从学习会话中提取学习总结和生活事件，统一写入记录文件。**只负责记录，不负责教学。** 所有内容先写进 `daily/{日期}.md`（单一真相源），再维护索引与标签倒排。

## 详细度要求（最高优先级）

记录的目的是让孩子和家长日后能**完整回顾"当时发生了什么"**。因此：

- **不限制篇幅**：不要只写一行或一两句。写清楚、写全。
- **记录所有关键点**：孩子的原话、举的例子、提的问题、情绪反应、思考过程、纠正过程，都要记下来。
- **不写空话**：禁止"表现很好""理解到位""很积极"这类概括，必须写具体发生了什么、孩子具体说了什么。
- **宁详勿略**：拿不准要不要记，就记下来。多记无害，漏记才是损失。

## 工作流程

### 1. 读取主题映射

读 `learning/topics.md` 的 frontmatter，获取所有主题及其文件位置：

```yaml
topics:
  - {name: 论语, file: lunyu/lunyu.md, method: learning/lunyu/method.md, progress: 3/20}
```

### 2. 提取学习总结

回顾当前会话，提取每个主题的学习总结，格式为：

```
【学习总结】{主题} - {课程名} | 掌握度: {程度} | 日期: {YYYY-MM-DD}
```

### 3. 更新学习进度 + 写 daily

对每个有学习总结的主题：

1. 更新 `learning/{topic}/{topic}.md` 对应 `### 课程名` 条目：状态 `⬜`→`✅`、填写掌握度
2. 更新其 frontmatter：`learned` / `total` / `next` / `updated`
3. 在 `daily/{日期}.md` 的「学习」区块按下方「详情格式」逐条详写

**重要：课程名不得改写、简写或添加注释，必须与教学输出完全一致。**

### 4. 提取生活事件 → 写 daily + life 索引 + tags 倒排

从会话提取孩子的生活事件（日常活动、兴趣表现、情绪状态、咨询求助等），对每个事件：

1. 写 `daily/{日期}.md` 的「生活」区块（按下方「详情格式」详写概要）
2. 追加 `life/{月}.md` 索引行（只指针，指向 daily 锚点）
3. **打标签**：只能从 `tags/taxonomy.md` 词表选；无法归类打 `其他`
4. 同步更新对应 `tags/{tag}.md` 倒排索引（关联知识点 + 关联生活事件）

## 文件格式

### daily/{日期}.md（单一真相源，4 区块）

#### ## 学习

每条学习记录用 `### 课程名` 作标题，下面逐字段详写。**「孩子表现」必填且必须详写，不限篇幅。**

```markdown
## 学习

### 论语先进篇第九章
- 课程名：论语先进篇第九章
- 考核：吟诵✓ 翻译✓ 道理应用✓
- 掌握度：熟练
- 难点："噫"是感叹词"唉"的意思，不是"益"
- 错题：无（自己纠正了读音选择）
- 孩子表现：能主动纠正自己的读音错误；用小华和小红的故事生动理解了孔子失去颜渊的悲痛；提出"送画送贺卡"的暖心方法珍惜友谊
```

**字段说明：**

- `课程名`：与进度文件 `###` 标题完全一致，不得改写
- `考核`：各项考核点及结果（✓ / ⚠️ / ✗），逐一列出
- `掌握度`：熟练 / 良好 / 学习中 等
- `难点`：孩子遇到的难点，以及你是如何讲解、纠正的
- `错题`：答错的题、错在哪、孩子如何纠正的
- `孩子表现`：**必填且详写**。记录孩子的原话、举的例子、提的问题、思考过程、情绪反应，不限篇幅。宁可多写几行，不要只写"理解到位"

#### ## 生活

每条生活事件用 `### 事件标题` 作标题，下面是标签和概要。**「概要」必须详写完整经过，不限篇幅。**

```markdown
## 生活

### 准备去奶奶家——珊珊自己列行李清单
- 标签：#日常 #独立
- 概要：珊珊说明天回奶奶家，自己列了清单：牙刷、牙膏、水杯、衣裤、手机、毛巾、内裤、论语/汉字宫/古诗学习资料、听力宝、笔、橡皮、营养品、水、三明治、零食、小老虎玩具、轻轻陶笛。饺子补充了袜子、睡衣、拖鞋、充电器、梳子、发圈等。
```

**字段说明：**

- 标题：一句话概括事件
- `标签`：从 `tags/taxonomy.md` 词表选，可多个
- `概要`：**详写完整经过**，包含起因、过程、结果，孩子的原话、情绪、想法，不限制一两句

#### ## 问答

孩子随口问的问题，记录孩子原话 + 引导过程 + 结论：

```markdown
## 问答

### 恐龙为什么灭绝
- 孩子的疑问：恐龙到底为什么灭绝呀？（原话）
- 引导过程：没有直接给答案，先反问"你觉得可能是什么原因"，孩子提出"是不是天变冷了"，再顺着引导思考
- 结论：一起得出小行星撞击导致气候变化的主流说法，孩子还追问了"那小鸟为什么活下来"
```

#### ## 任务

孩子让做网页/定时提醒/找资源等，记录需求 + 过程 + 产物：

```markdown
## 任务

### 做个番茄钟
- 需求：孩子要一个番茄钟，选了可爱的番茄风格，可自己调时间（15/20/25/30 分钟或自定义）
- 过程：孩子全程参与设计（选风格、选功能），主动表达自己的想法
- 产物：outputs/tomato.html
- 状态：done
```

### life/{YYYY-MM}.md（按月索引，只指针）

```markdown
## 2026-08-13 撒谎事件
- summary: 对妈妈撒谎 | type: consult
- tags: [诚实, 亲情] | 关联: daily/2026-08-13.md#生活
```

### tags/{tag}.md（倒排索引）

```markdown
# 标签：诚实

## 关联知识点
- 论语·吾日三省吾身 (learning/lunyu/lunyu.md)

## 关联生活事件
- 2026-08-13 撒谎事件 (daily/2026-08-13.md#生活)
```

## 注意

- **详细度**：不限制篇幅，记录所有关键点，宁详勿略。这是硬要求。
- 课程名必须与 `learning/{topic}/{topic}.md` 的 `###` 标题完全一致，不得改写
- 打标签只能从 `tags/taxonomy.md` 选，无法归类打 `其他`
- **写入顺序**：先写 `daily`（单一真相源），再更新 `life` 索引和 `tags` 倒排，保证 daily 先落盘
- 索引文件只放指针，不复制内容（详细内容只在 daily 写一次）
- 如无新学习总结或生活事件，跳过对应更新
- 每日达标评估（对照 rules 的必学内容完成表）由 study-tracker 技能负责，本技能不生成
