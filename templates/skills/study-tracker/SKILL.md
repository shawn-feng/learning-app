# 学习评估技能

## 职责

读取每日目标量和学习进度，评估当日必学内容完成情况，输出评估结果。

## 工作流程

### 1. 读取每日目标量

读 `learning/rules.md` 的 frontmatter，获取各主题的每日目标：

```yaml
rules:
  论语: {daily: 3, review: "全篇背诵", type: 必学}
  汉字宫: {daily: 2, type: 必学}
```

### 2. 读取各主题进度

通过 `learning/topics.md` 的 frontmatter 找到各主题进度文件（`learning/{topic}/{topic}.md`），读取每个主题的进度：

- `learned`：已学课程数
- `total`：总课程数
- `next`：下一课
- `updated`：最后更新日期

### 3. 评估当日完成情况

对每个主题，判断当日（根据 `updated` 字段是否等于今天）是否完成每日目标：

| 主题 | 每日目标 | 今日新增 | 完成情况 |
|------|---------|---------|---------|
| 论语 | 3 | 2 | 未完成（缺1） |
| 汉字宫 | 2 | 2 | ✅ 完成 |

### 4. 输出评估结果

在会话中输出当日学习评估结果：

```markdown
## 2026-08-13 学习评估

### 必学内容
- ✅ 汉字宫：已完成 2/2 课
- ⬜ 论语：已完成 2/3 课，还差 1 课

### 总结
今日完成度：4/5（80%）
建议：明日优先补上论语的剩余课程
```

### 注意

- 只读取和评估，不修改任何文件
- 课程名与进度文件保持一致，不得改写
- 若无当日数据，如实报告未完成
