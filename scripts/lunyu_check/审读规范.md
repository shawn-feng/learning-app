# 论语教学文案审读规范

## 背景
`data/children/1f050a7f-*/learning/lunyu/materials/` 下是面向儿童的《论语》教学文案（每章一篇 .md + .html）。已做过原文文字校对，现在要审读**翻译与解释部分**是否曲解原意。

## 权威基准
- 杨伯峻《论语译注》译文（已提取到对照文件每章「杨伯峻译文」字段，作为判定译文对错的权威）
- 钱穆《论语新解》白话试译（辅助参考）
- 南怀瑾《论语别裁》、傅佩荣《论语三百讲》讲解

## 审读对象（对照文件里的四个字段）
1. **教学文案翻译**：逐句白话翻译（核心审读对象）
2. **教学文案释义**：道理总结
3. 生活例子、历史典故（在原始 md 文件中，对照文件未包含，需另查）

## 判定标准（严格对齐原文）

### A 类：硬错误（必须报告）
1. **曲解原意**：译文把原文某个关键字词、句子的意思讲反了、讲错了。
   - 例：把「敬事而信」的「敬事」讲成「尊敬」而非「认真对待工作」；把「巧言令色」理解错。
2. **漏译关键内容**：译文跳过原文一整句或关键短语没有翻译。
3. **张冠李戴**：把甲章的内容/典故错安到乙章。
4. **史实错误**：典故中人名、朝代、事件与史实不符。
5. **读音错误**：多音字注音错误（如 说=shuō 应为 yuè）。

### B 类：偏离原意（较严重，需报告）
6. **释义跑偏**：道理总结偏离本章主旨，或引申出的道理与原文相悖。
7. **过度引申**：译文加入了原文没有的、且会误导孩子的具体信息（如凭空添加人物、对话、事件）。

### C 类：可接受（不报告）
- 儿童化的比喻、生活化改写（只要核心意思没错）
- 同义替换（如「高兴」vs「愉快」）

## 输出格式（每个错误一条）
```
[严重度] 篇.章 字段名
  原文：xxx
  错误译文：xxx
  问题：xxx
  建议改为：xxx
```
严重度：P0（曲解原意/史实错误）、P1（偏离/漏译）、P2（可改可不改的小瑕疵）

## 要求
- 逐章逐句审读，不漏章
- 只报真实存在的问题，不凑数
- 拿不准的先报告并标注「待核」
