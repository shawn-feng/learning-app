## ISSUE-041 备份+同步方案讨论（2026-08-25，仅方案未动代码）
- 范围拍板=**三位一体**：① 备份防损（本地 zip + 云端版本历史）② 换机全量迁移（同步范围扩到家长库/agents.sqlite/scheduler-config/app-settings/profile 去敏）③ 家长异地发课/查进度。
- 备份=时间点快照，客户端手动按钮+定时任务发起，**非实时**；防损=云端版本历史（N 版+不可变快照，防 last-write-wins 反向污染）。
- 异地=**异步轮询**：云端=存储+事件信箱 `sync_events`（assign_topic/send_materials/request_progress/push_data）；家长上传家长库→其他 app 拉取→分配主题写事件→孩子 app 轮询拉到→应用；进度查询=请求事件→孩子推送→家长读云端。**同一孩子单终端学习→LWW 安全无并发冲突；全场景低频→定时/手动，无需实时推送**。
- 技术路线：复用 sync-manager.ts + cloud-service sync.py（storage/{parent_id}/{child_id}/），不等 ARCHITECTURE-SPLIT 引擎服务端。
- 分层：层 A 备份防损（backup.ts + 云端版本历史 + restore 端点）→ 层 B 换机迁移（含家长目录全量同步）→ 层 C 异地（事件表 + 轮询循环 + 家长 UI 入口）。
- 待拍板小项：① 备份形式 zip vs 文件夹；② 是否含 .pi 会话历史（默认排除）。ISSUES.md ISSUE-041 已更新完整方案。
