## server 端部署到家庭局域网 192.168.1.201（Ubuntu 24.04 / Mac mini，用户 shanshan）
- **数据**：本机 `data/` 7G（parents 7G 课程资料 + children 20M + shared/auth.json 模型 key + app-settings 默认模型 + license）tar 流式传输到 `/opt/learning-server/data`（排除 data/.pi 客户端会话；⚠️ Windows tar 会保留 `data/` 顶层目录 → 解压成 data/data 嵌套，需 mv 修正）。
- **部署**：`/opt/learning-server/learning-server`（pkg linux 75MB）+ systemd `learning-server.service`（User=shanshan，SERVER_DATA_DIR=/opt/learning-server/data，SERVER_PORT=8788），active + 0.0.0.0:8788 监听。
- **⚠️ pkg 跨机踩坑**：本机 pkg 默认把 server.cjs 编成 V8 bytecode，在目标机跑报 "V8 rejected the bytecode cache"（跨机器 V8 版本不匹配）。修复：pkg.mjs 加 `--public-packages "*" --public`（源码明文打包，体积 +0.3MB）。
- **验证**：/api/v1/health {"ok":true,"db":"ok"}；Windows 跨局域网访问 192.168.1.201:8788 通；children 未带 token 401（鉴权生效）；license 需 session token。
- **客户端切换**：设置→通用设置→服务器地址填 `http://192.168.1.201:8788`（GeneralSettings serverUrl）。模型 key 在客户端本地 auth.json，AI 调用仍走客户端，不受影响。
- **磁盘**：201 原 92% 满，清理 ~/.cache(playwright/edge/huggingface 等) + npm cache + journald vacuum 腾出 ~7G；部署后 93%（8.8G 可用，⚠️ 紧张，materials 大文件上传需留意）。
- server 版本常量硬编码 0.1.0（/api/v1/version），package 0.1.1 只影响 pkg 打印；min_client_version=0.1.0 与客户端 0.1.4 兼容，未重打。
