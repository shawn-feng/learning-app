## 英语音标 emma 视频无法播放——修复：html 注入 <base>
- **根因**：音标页 phonetics.html 用 JS 动态拼接视频路径 `'emma/'+encodeURI(phoneme)+'.mp4'`（不在 href/src 属性），rewriteHtmlAssetRefs 只改静态属性；srcDoc(about:blank) 下相对路径解析失败。
- **修复**：readParentMaterial html 分支注入 `<base href="media://local/parent/<pid>/<fileDir>/">`（base 用 media:// 因 mp4 在 media 白名单，asset 白名单无视频；绝对 URL 不受影响）。⚠️ 踩坑：别 replace 双斜杠，`media://` 会被压成 `media:/`。
- **生效**：需重启客户端（dev）或重新打包发布；201 server 无需动。

## 孩子端英语材料 CSS 失效 + 第11课空白——修复 display_content 复用渲染处理
- **根因**：孩子端材料经 display_content 工具展示（srcDoc），但工具直接返回原始 html——相对 CSS/图片/JS 动态路径在 about:blank 下全失效；且**不跟随 meta-refresh 占位页**（第11课 index.html 是占位页跳 ../learn/grammar.html → 空白）。家长端 readParentMaterial 有处理所以正常。
- **修复**：parent-library.ts 抽出 `rewriteMaterialHtmlForRender`（rewriteHtmlAssetRefs + base 注入）并 export `followHtmlRedirectRemote`；custom-tools display_content 父库分支复用（follow 占位页 → rewrite → base 注入，DEFAULT_PARENT_ID 作协议路径段，数据经 session token 定位）。
- **生效**：客户端主进程改动，dev 重启 / 重新打包发布生效；201 server 无需动。
