# ISSUE-170：孩子端课程详情「学习资料」tab 顶部残留死返回箭头——去掉，资料正文上移

- **类型**：bug / UX（占一行的无效按钮）
- **现象**：学习进度 → 课程详情 →「学习资料」tab，资料正文上方有一个孤零零的返回箭头（无标题、点击无反应），白占一行高度，资料区域被压低。
- **根因（已核代码）**：ISSUE-157 让课程详情的「学习资料」tab 以 **bare 模式**复用 MaterialsPanel（`CourseDetail.tsx:551`，`onBack={() => {}}`、意图「无返回按钮/无标题」），但 `MaterialsPanel` 的 bare 实现只藏了标题、**返回 IconButton 照渲染**（详情两个分支各一处）——渲染出来的箭头 onClick 是 no-op，纯死按钮。
- **修复（2026-09-28）**：`MaterialsPanel.tsx` 详情两分支（正文兜底分支 + 主渲染分支）的头部行（返回箭头 + 标题）整体加 `!bare` 条件——bare 模式下整行不渲染，资料正文上移占满；非 bare（Learn 页聊天资料面板）不变，返回列表箭头保留（那里 onBack 有真实功能）。
- **验证**：electron-vite / web 双端构建过；行为核对：bare（课程详情 tab）无箭头无标题、正文上移；非 bare（聊天资料）箭头仍在且可用；空资料兜底分支同样不再出现死箭头。
- **优先级**：低-中（视觉/空间浪费，无功能损失——按钮本来就没功能）
- **记录时间**：2026-09-28（当日修复）
