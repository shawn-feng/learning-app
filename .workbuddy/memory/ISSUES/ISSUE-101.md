### 关键代码/数据模型（落地时直接套用）
- 题库表 `question_bank.answer` 即背诵题的**参考原文（refText）**，发音评测据此打分；`behavior='speech_recite'`、`scoring=NULL`、`point_max=10`。
- 课程↔知识点↔题 挂载在 `course_knowledge_questions`（`course_id`=courses.uuid，`knowledge_point_id`=背诵 KP id，`question_id`）。
- 现有工具已能写：服务端 `assess-content.ts` 的 `saveQuestion`（按 id 覆盖 answer/behavior）、`getOrCreateKnowledgePoint`、`replaceCourseContent`。家长 agent 也可经 `parent_exam_content_*` 系列落库。

### 为什么千字文是坏的
千字文-01 的「背诵」KP 下那条 recitation 题 `answer='重点字词（童趣版）'`，说明当初批量建课时把「童趣版解读」误填进了背诵参考文本列。孩子端背诵评测会用这个字符串当标准答案 → 永远对不上，且家长看到的是「背了但低分/不通过」。
