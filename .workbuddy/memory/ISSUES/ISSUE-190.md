# ISSUE-190：账号退到主页再进后，agent 一轮回复的「思考过程」被单列成空消息气泡

- **类型**：缺陷（会话历史回填 / 渲染）
- **优先级**：中（只影响「退出重进」后的历史观感与操作；实时聊天本身正常）
- **记录时间**：2026-10-21
- **用户原话**：「但账号退到主页再进后，一条agent消息的思考过程会被单列成一个消息气泡。这个要去掉，只需要最终回复消息气泡上的icon查看就行了。」
- **关联**：会话历史回填链路（ISSUE-100 / ISSUE-159 / ISSUE-107）；渲染层 `ChatWindow` 的 🧠 展开（历史恢复思考与工具记录）

## 现象（用户截图，2026-10-20 18:31 珊珊会话）

孩子聊天里 agent 完成一轮「建作业课」：查计划 → 建互动页 → 写 8 件事 → 回复。实时显示正常（一个工作气泡，最终变成一条回复）。

**但账号退到主页再进来**（重新走 `pi:start_child` → `/agent/:childId/open` 回填历史）后，同一轮变成：**7 个只有时间戳、没有任何正文的空气泡**（每个右侧还挂着 🧠 和 🔊 图标），然后才是最终回复气泡。用户要求去掉这些单列的思考气泡，思考只从最终回复气泡的 🧠 图标查看。

## 根因

服务端 SDK 会话里，**一轮 agent 回复不是一条 assistant 消息，而是多条**：

```
user: "今天的作业…"
assistant: [thinking, toolCall]      ← 只有思考 + 工具调用，没有正文
toolResult: …
assistant: [thinking, toolCall]
toolResult: …
…
assistant: [thinking, text]          ← 最终回复
```

`electron/lib/server-agent-client.ts` 的 `mapHistoryMessages`（以及 `web/src/shim/domains/agents.ts` 的同名移植）原来**逐条**映射：

```ts
if (text || thinking) out.push({ role: "ai", text, thinking, time });
```

于是「只有 thinking、没有 text」的中间消息被还原成 `{ role: "ai", text: "" }` 的 AI 气泡。`ChatWindow` 对 AI 消息固定渲染「气泡 + 🧠/🔊」，正文为空时就是一个空气泡 + 两个图标——正是截图里的样子。

而实时链路（`bridgeChildAgentEvents` → `pi:thinking` / `pi:reply`）整轮都 patch 同一个 working 气泡，思考只落在最后那条回复气泡上，所以**实时与回填的语义不一致**，问题只在「退出重进」暴露。

**影响面（本机 56 份历史会话扫描）**：47/56 份存在这种空气泡；最严重一份 458 条原始消息，修复前映射出 306 个气泡，其中 **152 个是只有思考的空气泡**（77 条真实 AI 回复）。

## 修复（纯客户端，服务端零改动）

按「**两条 user 消息之间 = 同一轮**」聚合，不再逐条产出气泡：

| 规则 | 说明 |
|---|---|
| 正文 | 仍一条一个气泡（与实时「多段文本各成一条」一致），不合并、不丢正文 |
| 思考 | 本轮所有 thinking 块合并（`\n\n` 连接），**只挂到最后一个正文气泡（最终回复）** 上；其它气泡不挂思考 |
| 空轮 | 整轮没有任何正文（中止轮 / 纯工具轮）→ 整轮不产出气泡，不再出现空气泡 |
| 时间 | 每个气泡仍用自己那条消息的真实时间；user 消息仍按原样回填 |

改动文件：

- `electron/lib/server-agent-client.ts` — `mapHistoryMessages`（约 :555）按轮缓冲 + flush；
- `web/src/shim/domains/agents.ts` — 同名函数（约 :95）同步同一份实现，保证手机/网页端刷新后行为一致。

## 验证（2026-10-21）

- **新增单测** `test/server-agent-client.test.ts`（describe「mapHistoryMessages（历史回填：思考不再单列空气泡）」，4 例）：
  1. 只有思考/工具调用的中间消息 → 不再单列气泡，思考并入最终回复；
  2. 一轮多段正文 → 各段仍是独立气泡，思考只挂最终回复；
  3. 整轮没有正文（中止/纯工具轮）→ 不产出任何 AI 气泡；
  4. 不同 user 轮次的思考不串泡。
- `npx vitest run test/server-agent-client.test.ts` → **31/31 通过**（含既有 27 例，无回归）。
- **真实会话回归**（本机最严重的 458 条会话）：修复前 306 个气泡（152 个空气泡）→ 修复后 **154 个气泡、77 个 AI 气泡全部有正文、全部带回合并后的思考（136~1998 字符）**，0 个空正文 AI 气泡。
- 构建：Web 端 `vite build` 转换阶段通过；本机最后一步 esbuild 清理临时文件报 `Access is denied`（`%TEMP%` ACL 环境问题，ISSUE-187/188/189 已多次记录，与本次逻辑无关）。

## 边界 / 待办

- **工具调用记录仍不恢复**（`mapHistoryMessages` 既有 TODO：toolCall 块 + toolResult 配对未做）——本次只修「思考被单列」，不扩大范围；最终回复气泡的 🧠 里能看到合并后的思考，但看不到工具列表（与修复前一致）。
- 中止轮 / 纯工具轮的思考在回填时**有意丢弃**（因为没有「最终回复气泡」可挂，且用户明确不要单列思考气泡）。
- 需要重新构建客户端（Electron 打包 / Web `web/dist` 换装）后生效；纯客户端改动，服务端 201 无需重新部署。
