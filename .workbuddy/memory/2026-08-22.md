  - `lib/pi-runtime.ts`：`getSharedRuntime()` 创建 runtime 后，读 settings.apiKeys 逐 provider 调 `runtime.setRuntimeApiKey()` 注入凭证（关键：让引擎真正认 key）；新增 `bumpRuntime()` 失效缓存。
  - `routes/settings.ts`：`POST /api/settings/apikey` 保存成功后调 `bumpRuntime()`，使下次对话/拉模型用新 key 重建 runtime。
