## ISSUE-190：退出主页重进后，思考过程被单列成空白消息气泡（修复）

**用户反馈**（附孩子端聊天截图，10-20 18:31 珊珊会话）：「但账号退到主页再进后，一条agent消息的思考过程会被单列成一个消息气泡。这个要去掉，只需要最终回复消息气泡上的icon查看就行了。」

**定位**：截图里 7 个空气泡 = 一轮 agent 回复中的「只有 thinking、没有正文」的中间 assistant 消息。服务端会话把一轮存成多条 assistant 消息（`thinking+toolCall` → `toolResult` → … → `thinking+text`），`mapHistoryMessages` 逐条映射时把 `text="" + thinking` 的中间消息还原成 AI 气泡；`ChatWindow` 对 AI 气泡固定渲染「气泡 + 🧠/🔊」，于是变成只有时间的空白泡泡。实时链路整轮 patch 同一个 working 气泡，因此只在「退出重进/重新登录」回填历史时暴露。本机 56 份历史会话扫描：47 份存在，最坏一份 458 条原始消息映射出 306 个气泡（其中 **152 个空气泡**）。

**修复**（纯客户端，服务端零改动）：`mapHistoryMessages` 改为按「两条 user 消息之间=同一轮」聚合——正文仍一段一个气泡（与实时逐段回复一致），整轮所有 thinking 合并（`\n\n`）只挂到**最后一个正文气泡（最终回复）**，点 🧠 展开；整轮没有任何正文（中止/纯工具轮）则整轮不产出气泡。同步修改：

- `electron/lib/server-agent-client.ts`（`mapHistoryMessages`）
- `web/src/shim/domains/agents.ts`（同名移植，保证网页端刷新后一致）

**验证**：`test/server-agent-client.test.ts` 新增 4 例（思考不单列/多段正文保留/纯工具轮不出泡/思考不跨轮串泡），该文件 31/31 全绿；真实最坏会话回归 458 条 → 154 个气泡（77 个 AI 气泡全部有正文、全部带回合并思考，0 空正文）。Web `vite build` 转换阶段通过，最后 esbuild 清理临时文件报 EPERM（`%TEMP%` ACL 环境问题，同 ISSUE-187/188/189，与本次逻辑无关）。

**待办**：重新打包客户端（Electron）与换装 `web/dist` 后生效；工具调用记录仍不恢复（`mapHistoryMessages` 既有 TODO，本次未扩大范围）。
