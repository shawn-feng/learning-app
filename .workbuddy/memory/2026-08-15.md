## 修复：断网时反复返回同一条旧回复

- 根因：SDK `session.prompt()` 出错不 throw，记 `stopReason:"error"`+`errorMessage`+空 content 在最后一条 assistant 消息；`pi:prompt` 提取 text 时跳过空 content、回退到历史旧文本，且 return success:true。
- 证据：会话 jsonl 最近 assistant 全 error/空；curl 直连 api.deepseek.com 验证 flash/pro/chat 模型、key、网络均正常（排除模型/鉴权）。
- 修复：ipc-handlers.ts 加 findLastAssistant/assistantError/friendlyError 三个 helper；pi:prompt 先检测最后 assistant 是否 error，是则发 pi:reply_error（"网络连接失败，请检查网络后重试"）+ return success:false。前端 handleReplyError 已有处理，无需改。
- 验证：构建✅ 测试 28/29（1 失败为既有 8005 云端注册环境问题）。
