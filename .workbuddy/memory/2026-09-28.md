## ISSUE-171：查词弹框 🔊 一点就消失且无声（当日报复修，事件冒泡竞态）

**现象/根因**：点 🔊 朗读 → 弹框消失、无声。useWordLookup 在 document 挂 mouseup 选区监听；Chromium 点按钮不清文本选区 → 点 🔊 的 mouseup 冒泡上去被当「新选词」→ 重锚定 + `setOpen(false)` 收回弹框 → React 卸载弹框（含按钮）→ click 永远派发不到 🔊 → onSpeak 没跑。

**修复**：WordLookupOverlay 弹框根节点 mousedown/mouseup/click 全部 stopPropagation（此前只拦 click），悬浮图标补 onMouseUp。弹框内部点击不再外漏；「点外部关闭」由外部 mousedown 直达 document 保证，Esc/选新词行为不变。双端构建过。详见 ISSUE-171。

**现象/根因**：学习进度→课程详情→学习资料 tab，资料上方有孤零零的返回箭头（点击无反应、白占一行）——ISSUE-157 的 bare 模式在 MaterialsPanel 只藏了标题、箭头照渲染，且 CourseDetail 传入的 `onBack={() => {}}` 使其成为死按钮。

**修复**：MaterialsPanel 详情两分支的头部行（箭头+标题）整体加 `!bare`——bare 模式整行不渲染、正文上移占满；非 bare（聊天资料面板）的返回列表箭头保留。双端构建过。详见 ISSUE-170。

## ISSUE-169：家长中心孩子详情页盖住侧栏菜单切换（当日报复修）
