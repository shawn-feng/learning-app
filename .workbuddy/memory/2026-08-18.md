## 修复（22:27）：autoNewSession 上线后 node-cron 崩溃 TypeError

- 现象：`npm run dev` 启动后每分钟 cron 报错 `Cannot read properties of undefined (reading 'lastRun')`，来自 `startScheduler` 读 `cs["auto-new-session"].lastRun`。
- 根因：`getChildState` 只在「该孩子完全不在 state.children 里」时补 `auto-new-session` 键；而磁盘上已有的 `task-state.json` 里珊珊/闻闻早已存在、且是旧结构（无 `auto-new-session` 键），于是 `cs["auto-new-session"]` 为 undefined，cron 读到 `.lastRun` 崩。
- 修复（electron/lib/scheduler.ts）：
  1. 抽出 `defaultChildTaskState()`；`getChildState` 改为**对每个孩子都做任务键合并**（保留历史 lastRun、补齐缺失键），任何老结构/未来新增键都向前兼容，不再崩溃。
  2. 导出 `getChildState` 与 `TaskState` 接口作为测试 seam。
- 测试：新增 `test/scheduler-task-state.test.ts`（3 用例：老结构补齐键且保留旧 lastRun / 嵌套键兜底 / 全新孩子完整四键）全过。
- 验证：tsc 0 新增错误；全量 `npx vitest run` → 48 passed / 2 failed（app.test.ts 云端 ECONNREFUSED 既有；sync.test.ts 为全量并发下的已知 5s 超时 flaky，单独跑 8/8 通过，非本次引入）。
