## ISSUE-124 家长聊天框上传图片 agent 读不到 uploads（bug 兼需求）
- 现象：家长聊天框上传珊珊语文作业图，agent 自查后说图片落在 `parents/<pid>/uploads/`（家长上传区），但「读不到」——它试了 parents/…、uploads/… 都返回「材料不存在/目录不存在」，只能让家长文字描述作业。
- 根因（读源码定位）：①上传落点 `parents/<pid>/uploads/`（相对 dataDir；`db/parent-lib.ts:3` 家长维度目录约定）；②`parent_read_image`（`agent/parent-tools.ts:1202`）虽已写 `uploads/`/`files/` 分支，却是**半成品**——agent 收到的路径带 `parents/<pid>/` 前缀、不以裸 `uploads/` 开头 → 走 `materialAbsPath` 去材料库（`materials/<pid>` 根）找 → 不存在；且即使传裸 `uploads/xxx`，`resolveWithin(dataDir, rel)` 解析到 `dataDir/uploads/xxx`、**缺 `parents/<pid>/` 段** → 仍读不到。③视觉模型能力本身存在（`vision.ts:62` `describeImageViaVision`，被该工具调用），只差把 upload 文件喂进去。
- 结论：**能读图+调视觉模型的工具是有的**（`parent_read_image`），但当前因 uploads 路径解析 bug + 前缀不匹配读不到家长上传区；材料库/家长库工具全碰不到 uploads。属高优先级（卡住「上传作业图→读图→转课程」主流程）。
- 方案：F1 修 `parent_read_image` 识别 `parents/<pid>/uploads/`、`parents/<pid>/files/` 并校验 pid==当前家长防越权；F2 家长端「转存为资料」入口；F3 prompt 引导；F4 端到端联调+冒烟。索引 123→124，详情 `ISSUES/ISSUE-124.md`。
