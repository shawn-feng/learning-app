## 视频无法播放根因：media:// handler 不转发 Range + 服务端 Range 未生效
- **现象**：非洲鼓/陶笛/英语/千字文主题视频无法播放，小篆能播；音频正常。
- **排查链**：编码全 h264 High（排除）→ 索引全有行（排除）→ html/JS 同模板（排除）→ moov 位置：非洲鼓/千字文在尾部、陶笛/英语在头部（**矛盾**）→ **Edge headless file:// 直播四个主题视频全部 loadedmetadata+canplay**（决定性：文件本身没问题）→ 问题在 HTTP 链路。
- **根因**：Chromium `<video preload="metadata">` 加载发 `Range: bytes=0-` 期望 206；①服务端旧进程无 Range（返回 200 全量，改动未生效 uptime 13h+）；②客户端 media/asset handler 用 fetchMaterialContent **全量 arrayBuffer + 不转发 Range**。结果：moov 尾部（非洲鼓/千字文）读不到 metadata 黑屏；moov 头部但 JS 立即 seek 分段起点（陶笛首段 02:08）→ seek 失败黑屏；**小篆 moov 头部 + 首段 00:03 几乎不 seek → 从头流式侥幸能播**。
- **修复（客户端 media-protocol.ts）**：新增 `proxyMaterial(rel, request)`——转发请求 Range 头到服务端 content/:id，**流式透传 upstream.body**（不再 arrayBuffer 大视频），透传 200/206/416 + Content-Range/Content-Length，Content-Type 用本地 MIME 表；media:// 与 asset:// handler 都改用它。tsc 0 错、单测 7/7 过。
- **必须两端重启**：服务端（Range 206 生效）+ 客户端（handler 生效）。重启后视频应全可播（含 seek 分段跳转、拖动进度条）。

## 白名单授权「授权不合法」修复（19:5x）
- **根因**（对照抖音官方文档 developer.open-douyin.com sdk/web-app/web/permission + partner 获取授权码页）：
