# 2026-10-22

## ISSUE-191：录音音量阈值改为按孩子单独设置 + 家长端聊天不做音量检测（已实施，未部署）

**用户要求**（承接 ISSUE-183/189）：「为每个孩子单独设置音量阈值。因为每个孩子的设备不一样，年龄也不一样。家长就不需要音量阈值检测。」入口位置用户拍板：**设置 → 发音评测页**。

**改前现状**：阈值是家长级一条线 `assessment_config.minVolumeNorm`（默认 42，0=不校验），一个家长下所有孩子共用；家长端聊天与孩子端共用 `ChatWindow`，也走同一个音量门并显示孩子的达标线音量条。

**实施**：
- **数据**：`assessment_config` 新增 `minVolumeNormByChild: { childId: 0-100 }`（AES 加密 JSON 内），原 `minVolumeNorm` 降为默认线；解析优先级 `minVolumeNormByChild[childId] ?? minVolumeNorm`；childId 为空 = 家长上下文 → 0（不检测）。
- **设置页**：保留「默认录音最低平均音量」滑条 + 新增「每个孩子的录音阈值」逐孩子滑条（`childList` 拉孩子；「用默认」提交 null 删除覆盖、保持继承）。
- **保存**：服务端 `applyAssessmentConfigPatch` 合并式更新——只改传入条目、null 删除、旧客户端不带字段时整表保留。
- **客户端**：`useVolumeThreshold(childId)` 按孩子分键缓存并解析；`ChatWindow` 家长端跳过音量拦截/解码测量、不显示实时音量条；`VolumeCheckModal` 收 `childId`。
- **服务端**：`/exam/config/:childId` 的 `examRules.minVolumeNorm` 与 `/assessment/assess` 兜底都按孩子解析；家长试音（childId 空）不校验。

**验证**：`issue191-per-child-volume` 13 例 + `issue183-volume-gate` 扩 4 例（按孩子 60 拦/0 不拦/另一孩子回退默认/家长试音不拦）+ `issue189` 16 例 + `assessment-type-thres` 3 例，共 **40/40 全绿**；server/client 改动文件 tsc 零错；web 生产构建过（`TEMP=<repo>/tmp/esbuild-tmp`）。

**待办**：部署服务端 + 重打包客户端 + 换装 `web/dist`；真实麦克风端到端（同设备不同孩子阈值分别生效、家长端不再拦截）待打包后实测。详见 `ISSUES/ISSUE-191.md`。
