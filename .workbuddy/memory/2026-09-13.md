## 修复：服务端 agent 事件到渲染层展示的三处断裂（commit `043ae37`）

### 症状（用户报）
1. display_content 前端没展示资料，左侧无内容；2. agent 部分思考/工具调用在客户端没展示；3. 工具调用只返回 `[object Object]`，无详细信息。

### 根因（P4「SSE 事件 → 渲染层」桥接层断裂，均为明确 bug）
1. **display_content 协议断裂**：服务端 `display-tool.ts` 改为「SSE 推 `display_content` 事件（只带 path/title/source，无正文）」，但渲染层既没订阅 `pi:display_content`，`handleToolEnd` 还在找已废弃的 `result.details.panelContent`——两条路都断。
2. **工具结果不展示**：`translateAgentEvent` 的 `tool_end` 发 `result`，但渲染层 `handleToolEnd` 读 `resultPreview`——字段名不匹配。
3. **`[object Object]`**：`translateAgentEvent` 用 `String(args)`，args 是对象 → `"[object Object]"`。

### 修复
- `server-agent-client.ts`：新增 `previewArgs`（对象 JSON.stringify）/ `previewToolResult`（从 result.content 提文本）纯函数；`tool_start` 发 `argsPreview`、`tool_end` 发 `resultPreview`；`bridge` 的 `message_end` 若消息含 thinking 块则补发完整思考（`complete=true` 覆盖式）。
- `display-tool.ts`：`display_content` 事件带 `content` 正文（fs.readFileSync）。
- `preload.ts`：新增 `onPiDisplayContent` 监听 `pi:display_content`。
- `Learn.tsx`：抽 `applyDisplayContent`（写 materials 列表 + 自动打开 + 场景判定）；新增 `handleDisplayContent` 订阅 `pi:display_content`；`handleThinking` 支持 complete 覆盖。
- `ParentChatPanel.tsx`：`onPiThinking` 同步支持 complete 覆盖。
- 验证：客户端 build 全绿；服务端 build + agent-session-check 全过；`server-agent-client` 单测 15→21 项全过；全套件 244 通过 / 11 失败（均为改动无关既有失败：assessment 4 / page-bridge 2 / assess-guide 2 / mastery 字段 3）。
