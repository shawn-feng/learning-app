## 5. 家庭隧道（201 → ECS，公网入口的另一半）

```
201: ecs-tunnel.service (User=shanshan)
  /usr/bin/ssh -N -o ServerAliveInterval=30 -o ServerAliveCountMax=3
    -o ExitOnForwardFailure=yes -o StrictHostKeyChecking=accept-new -o ConnectTimeout=15
    -i /home/shanshan/.ssh/ecs_tunnel_key
    -R 127.0.0.1:18788:127.0.0.1:8788
    -p 2222 tunnel@47.96.154.226
  Restart=always / RestartSec=10          # 断网自愈；ExitOnForwardFailure 保证绑口失败即重连
```

- **ECS 侧账号**：`tunnel`（shell=/usr/sbin/nologin，`usermod -p '*'` 解锁）；`authorized_keys` 单行选项 **`restrict,port-forwarding`**——只能转发端口，不能拿 shell、不能执行命令、不能开 pty；密钥 ed25519（201 生成，公钥 2026-10-03 部署）。
- **风险说明（2222 全网开放为何可接受）**：该口只能以 `tunnel` 用户密钥登录（`PasswordAuthentication no` 全局生效），且该用户被 `restrict` 锁死为纯转发；攻击面 = OpenSSH 自身（无凭证者无任何可利用路径）。
- **方向性**：连接由 201 主动外连建立（出站），家庭路由器/光猫零配置，动态公网 IP / CGNAT 均不受影响；ECS 上 `-R` 绑定 127.0.0.1（sshd `GatewayPorts` 默认 no），公网无法直连 18788。
- **server 端要求**：`/opt/learning-server/server.cjs` ≥ 0.5.19（开放 API + 语音）。

## 6. 变更/运维通道（无 SSH 也能操作的路径）

| 操作 | 通道 |
|---|---|
| ECS 执行命令 | 云助手 RunCommand：`python scripts/aliyun-run.py "<shell>" [--timeout N]`（AK：`docs/aliyun-aksk.txt` = CLI profile `learning-deploy`；实例 ID 内置） |

| 证书续期验证 | ECS 上 `certbot renew --dry-run` |

## 8. 边界与红线

1. **open 域名只放行 `/api/v1/open/`**——改 open-tunnel conf 时严禁加 `location / { proxy_pass ... }` 之类整站转发（会把家长 JWT 接口暴露公网）。
2. **tunnel 账号不提权**：不加 sudo、不改 shell、authorized_keys 的 `restrict,port-forwarding` 选项不动。
3. **AK 最小化**：`docs/aliyun-aksk.txt`（learning-deploy 子账号）勿入 git（当前在 .gitignore 外的 docs/ 下，注意）；如泄漏到 RAM 控制台吊销重建。
4. 201 数据安全网：`/opt/learning-server/data/backups/deploy-*`（每次部署自动备份 bundle + SQLite + kb/parents）。
