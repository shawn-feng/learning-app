## 一、产品简介

「学习伙伴」是一款运行在 Windows 电脑上的**桌面学习应用**（Electron 桌面应用），主要面向「家长 + 孩子」双角色：

- **家长**用它在工作台里管理孩子、编排课程与学习计划、查看学习情况、配置 AI 与积分规则。
- **孩子**用它在拟人化 AI 伙伴的引导下学习、练习、参加考核、赚取积分。

核心特点：

| 特点 | 说明 |
|---|---|
| 双角色隔离 | 家长工作台与孩子学习界面完全分离；孩子的学习数据、进度、会话彼此独立、按孩子隔离。 |
| 拟人化 AI 伙伴 | 每个孩子有专属的 AI 名字与性格，AI 了解孩子的姓名、年龄、年级、兴趣等基本情况。 |
| 云端 + 离线 | 认证后可离线使用；学习数据可多设备云端同步。 |
| 多模型支持 | 家长配置一个或多个大模型（含 API Key），所有孩子共用模型池；孩子学习时可自行切换默认模型。 |
| 语音化学习 | 内置发音评测（背诵/朗读）、语音问答（ASR）、点读发音，支持中英文。 |

## 二、首次使用与登录

### 2.1 家长账号（云端）

1. 打开应用，进入**家长登录页**（ParentLogin）。
2. 在云端注册 / 登录家长账号。
3. 登录成功后，云端会下发本账号的**许可信息**：允许的孩子数量、可用功能、订阅有效期。
4. 许可缓存在本地，**订阅到期前可离线使用**；到期后需重新联网认证。

> 💡 家长账号在云端（公网认证服务）管理，密码与订阅不上传到学习资料库。

### 2.2 添加孩子 ⚙️

在家长端「孩子管理」中添加：

1. 填写孩子**姓名**、选择**头像**；
2. 设置**孩子登录密码**（加密后随孩子档案保存到服务端，多设备登录一致；本地仅保留离线回退缓存）；
3. 配置孩子的 **AI 伙伴名字与性格**（决定 AI 以什么身份、什么风格陪伴孩子）；
4. 填写孩子**基本情况**（年龄、年级、兴趣等，AI 会据此个性化引导）。

添加后，孩子即出现在登录/选择界面，通过头像 + 密码进入自己的学习空间。

### 2.3 配置模型 ⚙️

1. 进入「设置 → 模型与 API Key」；
2. 添加一个或多个模型（选择提供商 + 填写 API Key + 模型 ID）；
3. 设置**默认模型**；孩子在学习时可自行切换。

> 所有孩子共用同一模型池与凭证，由家长统一管理。

## 三、家长端功能

### 3.1 家长工作台总览 ⚙️（Dashboard）

家长登录后进入**工作台主页**，可一眼看到：

- 各孩子的**学习进度概览**（已学/总课程、下一项、最近学习时间）；
- 各孩子的**积分余额**；
- 进入各管理模块的快捷入口（课程、计划、考核、积分、资料、设置）；
- 学习**看板**（LearningDashboard，家长/孩子复用，图形化展示进度）。

### 3.2 孩子管理 ⚙️

在「孩子管理」中可以：

- **添加 / 删除孩子**；
- **重置孩子密码**；
- **编辑 AI 伙伴名字与性格**；
- **更新孩子基本情况**（年龄、年级、兴趣）；
- 查看每个孩子的学习情况（进度、日志、考核结果）。

> 删除孩子会移除其本地学习空间；请谨慎操作。

### 3.3 主题与课程管理 ⚙️

「学习伙伴」以**主题（学科）→ 课程**组织教学内容。家长库是课程与资料的**唯一真源**（服务端存储，跨孩子共享）。

#### 3.3.1 主题管理（TopicEditor）

一个主题 = 一门学科或系列（如「国学」「英语」「数学」）。家长可以：

- **新建主题**（含五步引导式向导：意图 → 结构草稿 → 生成内容 → 关联资料 → 确认落库并分配给孩子，第 5 步需家长确认）；
- 编辑主题**教学方法**（method，决定 AI 如何教这门课）；
- 将主题**分配给孩子**（分配时会把课程快照拷贝到孩子库，孩子侧即可学习）。

#### 3.3.2 课程管理（CourseManager / CourseDetail）

每个主题下包含若干**课程**。家长可以：

- **新建 / 编辑课程**：填写课程标题、教学方法（lesson_method）、教学文案（teaching_copy）、学习资料路径（html_path）、考核要点；
- **上传学习资料**（见 3.9）：资料会落到服务端真源，孩子端自动可见；
- **查看课程详情**：课程详情页展示**教学方法、标签、考核要点**三项（逐题考核记录与掌握度不在此页展示，统一在「考核记录」查看，见 §3.5.3）。

> 课程详情页标签（tags）可在主题/课程详情页直接编辑（ISSUE-045）。

#### 3.3.3 英语场景课（特殊课程形态）

英语学科采用「**学习 + 场景合一**」：一门课 = 一个真实场景（如问候、颜色、食物、身体……），课内先学后练、一次进入完成闭环。详见 §4.4。

### 3.4 学习 / 考核 / 生活计划 ⚙️👦（StudyPlanPanel）

家长与孩子都可以通过**各自的 AI 伙伴对话**来编排计划——**排计划是「说给 AI 听、由 AI 实际操作后台」，而不是手工填表单**。家长对 AI 说「明天上午安排珊珊学《静夜思》」「本周每天考一次英语食物课」，孩子也可以对自己 AI 说「我想每天练 10 分钟书法」。所有计划统一在「今日计划」里按窗口自动出现。

三类计划：

| 计划类型 | 含义 | 完成的判定条件（由系统 / AI 自动打勾，孩子不手动勾选） |
|---|---|---|
| **学习计划** | 安排某天学某门课（具体到课程） | 系统在窗口内检测到该课程发生了学习 → 自动标记完成 |
| **考核计划** | 安排某天对课程的知识点做考核（含背诵/朗读/选择/问答等题型，**不限于语音考核**） | 孩子在考核页提交了该场次 → 自动标记完成 |
| **生活计划** | 生活安排（如刷牙、运动） | AI 根据对话内容判定完成与否，写入每日记录 |

**制定人分组（影响积分）：**

- **「必须完成项」**：家长制定的计划（孩子必须完成；未达标会按规则扣分）。
- **「加分项」**：孩子自己制定的计划（只加不扣，且需满足门控条件才加分，见 §3.6）。

> ⚠️ **孩子端不能手动勾选完成任何计划**——学习、考核、生活计划都不行。所有计划的「完成 / 未完成」都由系统在满足条件时自动判定并打勾：学习 = 检测到学习发生、考核 = 提交场次、生活 = AI 据对话判定。家长拥有**修正权**（可撤销「已完成」或标记取消），这是修正误判、停止计划无限累积的唯一手段。

**重复规则（plan_recurrences）：** 可设置每日 / 每周固定项（如「每天背 5 个单词」），系统每天自动展开成当天的计划行。

### 3.5 学习考核管理 ⚙️（ExamAdminPanel / ExamRecords / QuestionBank）

#### 3.5.1 排考核（安排一次考核计划）

考核是对**课程的知识点**做考核，题型包括**背诵 / 朗读（发音评测）、选择题、问答题**，**不只是语音考核**。

- **固定档（每日 / 每周）**：系统按学习计划周期内「必学课程」自动全部考核（规则内置，不走 AI）；
- **自定义档**：通过家长 AI 对话指定**精确课程名**，并可在本次覆盖考核方法（如「本次只考背诵」「本次不考选择题」），优先级最高。

**一次考核计划里能编排什么（以课程为基本单位）：**

- 选定要考核的**课程**（可一次排多门课）；
- 对每门课，可进一步**选定要考核的「知识点」**（课程的细分学习单元）——只考指定的知识点，不考整门课；
- 可指定本次考核方法（题型构成、背诵通过线等）。

> 知识点是课程的细分单元（见 §3.5.2）；考核以课程为容器、以知识点为实际抽题范围。

#### 3.5.2 知识点与题库（QuestionBankPanel）

考核内容已**结构化**，围绕「**知识点**」组织（不再使用「考核类别」概念）：

- **三层对应关系**：**主题 → 课程 → 知识点**。课程是最小的学习与考核单位（见 §3.3）；**知识点挂在课程下**，是课程内部的学习 / 考核细分单元。
- **题目 ↔ 知识点**：题库（question_bank）中的每一道题都对应**一个或多个知识点**；考核时系统按所选知识点从题库抽题。
- **知识点 → 课程 → 主题**：知识点归属课程，课程归属主题，由此可逐层追溯「某主题下都考了哪些知识点、孩子掌握得怎样」。
- 每道题可带评分标准、题级行为（背诵评测 / 朗读 / 口述）、选择题选项、知识点概要。
- 家长可在「题库」菜单查看全量题目与每个孩子的**最近得分**。

#### 3.5.3 查看考核记录

- 进入「孩子管理 → 考核记录」（ExamRecords）：左侧列表、右侧详情，查看每场考核的**逐题得分与逐题考核记录**；
- **掌握度与逐题考核记录不放在课程详情页**，统一在这里查看（见 §3.3.2 课程详情页口径）；
- **掌握度口径**：取孩子**最近一次考核的得分率**；**学习状态**取**最近学习时间**。

### 3.6 积分奖励体系 ⚙️（家长配置 + 孩子端兑换）

积分是「坚持与进步」的可见化，不是工资——必须满足阈值才发放。

#### 3.6.1 积分怎么算（每天结算一次）⚙️

积分**每天结算一次**，有两个独立来源，各自分档、各自算分：

1. **todolist 完成率**（来自学习 + 生活计划）
2. **考核得分率**（来自当天已提交的考核场次）

积分按**制定人分两组**分开结算（详见「加分项是什么」）：

- **「必须完成项」** = 家长制定的计划：孩子必须完成，未达标会**扣分**；
- **「加分项」** = 孩子自己制定的计划：只加不扣，且受门控约束。

**① todolist 完成率怎么算**

系统每天统计当天归属的计划项（学习 + 生活）：

- 分母 = 当天「归属日」内、计入完成率（count_in_rate=1）、未取消的计划条数；
- 分子 = 其中被判定为「已完成」的条数；
- **完成率 = 分子 ÷ 分母**（pending 未到期的不计入分母；cancelled 取消的不计）。
- **归属日规则**：按时完成的，在**完成那天**计入；到期未完成的（missed），只在**最后一天（due_at 当天）**计入分母；所以一条计划只会在一天进统计，不会重复扣分。
- 按归属日算出的完成率，落入下方「待办默认档」得对应积分。

**② 考核得分率怎么算（每天算总分）**

- 当天**有已提交的考核场次**才结算考核分；没有考核就不结算、不扣分；
- **得分率 = 当天该组已完成场次的 Σ得分 ÷ Σ满分**（多场次按分值加权合并成一个总分）；
- 按得分率落入下方「考核默认档」得对应积分。

家长在「积分奖罚设置」中按比例区间配置档位与每档积分变动（档数不固定，默认 4 档，可增删/改名/改区间/改分值）：

**待办（学习计划 + 生活计划）默认档：**

| 完成率 | 档位 | 积分 |
|---|---|---|
| 0–60% | 不合格 | −10（仅「必须完成项」扣分） |
| 60–80% | 合格 | 0 |
| 80–100% | 良好 | +10 |
| 100% | 优秀 | +20 |

**考核默认档：**

| 得分率 | 档位 | 积分 |
|---|---|---|
| 0–80% | 不合格 | −15（仅「必须完成项」扣分） |
| 80–90% | 合格 | 0 |
| 90–100% | 良好 | +10 |
| 100% | 优秀 | +20 |

**门控（加分项解锁条件）：**

- 待办：必须完成项完成率 ≥ **100%**，加分项才加分；
- 考核：必须完成项得分率 ≥ **90%**，加分项才加分；
- 「加分项」永远不扣分（命中负分档按 0 处理）；
- 若加分项达标但门控未开，系统会提示「本次未加分：必须完成项还没完成」。

**扣分口径：** 按当天未完成的比例扣分（完成率命中负分档），不按条数；负分档按天累积、不封顶。

**加分项是什么：** 「加分项」就是**孩子自己制定的计划**（学习 / 考核 / 生活计划孩子都可以自己定，见 §3.4）。它只加不扣：当孩子的计划完成率 / 得分率命中加分档时，只有在对应的「必须完成项」达到门控阈值（待办 100% / 考核 90%）的前提下，才会真正加分；否则本次不加分（仅记录「未解锁」）。

#### 3.6.2 兑换目录与审批（家长端）

- 家长在「兑换目录」中定义可兑换物品与分值（APP 内虚拟权益 / 向家长申请的现实权益）；
- 孩子提交现实权益兑换申请后，推送到**家长待办**；
- 家长履约完成后标记「已兑现」，系统扣除对应积分（扣减在履约完成时发生）。

#### 3.6.3 积分流水

每一分变动都记录原因（完成率/得分率、命中档位、来源），家长与孩子均可查看明细流水，余额由流水推导。

### 3.7 家长 AI 助手 ⚙️（聊天）

家长工作台内置 **AI 助手对话入口**，覆盖三大能力域：

| 能力域 | 能做什么 | 示例 |
|---|---|---|
| **配置管理（Control）** | 查看/修改配置（默认模型、资料上限、定时任务、孩子档案） | 「把默认模型改成 XX」「资料上限调到 30」 |
| **数据洞察（Insight）** | 只读查看孩子进度、掌握度、每日记录、多孩子对比 | 「珊珊这周学得怎么样？」 |
| **内容管理（Curriculum）** | 建/改课程与主题、上传学习资料、排学习计划与考核 | 「建一个唐诗主题」「上传这份资料」 |

**操作分级（安全边界）：**

- 自动执行：查询、生成草稿、写教学文案、资料文件读写；
- 家长确认后执行：新建/删除课程与主题、调整配置、分配主题、排计划落库；
- 永不触碰：认证/账户/密码、删除孩子数据、直接改数据库。

> 修改高影响配置时，AI 会先请家长确认再执行，并保留原值备份可回退。

### 3.8 每日记录与对话回顾 ⚙️（SessionReview）

- 家长可在孩子详情页查看**「📅 每日记录」**：按日期范围 / 分类 / 标签 / 标题筛选查看孩子每天的学习与生活记录；
- **对话回顾 / 导出**（ISSUE-044）：家长可回顾孩子与 AI 的对话内容，并导出；孩子聊天上传的资料归属家长目录管理，边界清晰。

### 3.9 学习资料库 ⚙️（家长端）

家长可上传与管理学习资料（HTML / 音视频 / 图片 / 文档），资料落到**服务端真源**，按主题目录组织：

- 资料在家长目录 `materials/<家长ID>/<主题>/...` 下；
- 支持**场景互动页**（角色扮演）、**随堂测验**、**绘本**等富交互资料；
- 所有资料页通过统一的 **PiBridge 通讯标准**与宿主/AI 交互（点读发音、提交答案、语音交互等）；
- 上传的资料孩子端自动可见，跨重启持久展示。

> 资料渲染支持 Markdown 与 HTML；视频须为 H.264 编码。

### 3.10 系统设置 ⚙️（Settings）

| 设置项 | 说明 |
|---|---|
| **模型与 API Key** | 配置模型池、默认模型（见 2.3） |
| **语音 / 评测配置** | 配置发音评测服务商与凭证（腾讯云智聆 / 阿里云声希，可切换默认 provider）；凭证加密保存在服务端，多设备同步 |
| **定时任务** | 配置每日记录总结时间、自动新建会话（跨天/定点） |
| **备份与恢复** | 服务端备份 / 恢复（zip 包） |
| **资料上限** | 孩子端资料展示上限（默认约 20，家长可改） |

## 四、孩子端功能

### 4.1 进入学习 👦（ChildSelect）

1. 在登录/选择界面选择自己的**头像**；
2. 输入**密码**进入学习界面；
3. 顶部显示 AI 伙伴的名字与头像，开始与 AI 互动。

### 4.2 学习主界面 👦（Learn）

学习界面采用「**内容面板 + 对话区**」双栏布局：

- **内容面板（左/上）**：展示 AI 推送的教学内容——课文原文、图片、知识点卡片、学习资料（Markdown / HTML）；
- **对话区（右/下）**：孩子与 AI 伙伴互动——朗读、讲解、提问、考核、鼓励；
- **输入栏**：孩子打字或语音输入，发送与 AI 交流。

**AI 伙伴会：**

- 以拟人化身份陪伴，知道孩子的名字与基本情况；
- 引导孩子进入主题/课程学习；
- 在过程中推送资料、提问、纠错、鼓励；
  - 孩子可自行**切换模型**（家长设默认，孩子可改选）。

孩子同样可以请 AI 伙伴帮自己排计划（学习 / 考核 / 生活皆可），自己定的计划属于「加分项」（见 §3.6）。

### 4.3 课程学习 👦

1. 孩子告诉 AI「我想学 XX」或点击今日计划中的课程；
2. AI 调用该主题的教学技能，读取进度确定下一课；
3. **教学 + 考核**：AI 推送资料、讲解知识点、带孩子朗读跟读、提问互动；
4. 教学结束后 AI 输出**学习总结**，进度自动记录；
5. 资料支持**点读发音**与**查词浮层**（WordLookupOverlay）——遇到生词可划词查音标/释义。

### 4.4 英语场景课 👦

英语作为一门普通学科，但有两处特殊体验：

**① 全程英文 + 独立子会话**

- 进入英语课时，AI 用**英文**教学（零基础可开「中英混合」兜底，孩子连续不理解时自动中文解释）；
- 每门英语课使用**独立子会话**（干净上下文，避免中文课对话干扰），孩子看不到其他课的历史气泡。

**② 场景角色扮演（学 + 练合一）**

一门英语课 = 一个真实场景（如 Food 课 = 甜品店）。流程：

1. **Stage1 学**：AI 全英文开场 → 展示场景单页资料（场景词卡 + 关键表达 + 示范剧集视频）→ 带孩子点读跟读；
2. **Stage2 练（角色对话）**：AI 切换角色（如店员），用英语带孩子自由对话、自然纠错、控制用词在已学范围；
3. **发音测评**：练习末 AI 挑 1–2 个重点句引导跟读，复用发音评测链路；
4. 结束 → 对话进入每日记录，家长可回顾。

### 4.5 学习考核 👦（ExamView）

孩子对**已学课程**做结构化考核（背诵/朗读、选择题、问答题多种题型，不限于语音考核）。

**入口分两区：**

- **今天可参加**：当天待考 / 已开始；
- **历史**：过去未完成 → 补考；已完成 → 查看成绩。未来排期不显示。

**答题形式（按题型）：**

| 题型 | 答题方式 | 判分 |
|---|---|---|
| **背诵 / 朗读题** | 朗读标准原文（页面**隐藏原文**，防看文朗读） | 录音上传发音评测，总分 ≥ 通过线才算通过 |
| **选择题** | 看选项说出你选哪个（页面显示选项列表） | 本地规则判分（说「选B」或念正确项即满分） |
| **问答题** | 口述回答（ASR 转写可修改） | AI 逐题判分 |

**发音评测说明：**

- 录音上传到**服务端**完成评测（凭证统一保存在服务端并加密，客户端只负责录音与结果回显）；
- 支持两家服务商并存：腾讯云智聆（中文 `cn_*` 用 `16k_zh`，英文用 `16k_en`）、阿里云声希（中文 `cn.pred.score` / 英文 `en.sent.score`）；
- 单题评测失败会**软失败**（记 0 分并注明原因，不阻断整场）；
- 题型自动选引擎；可在设置页切换默认 provider。

**提交后：** 逐题判分，结果落库，家长端可查看逐题得分与掌握度。

### 4.6 我的积分 👦

孩子端可查看与使用积分：

1. **余额与明细**：查看当前积分、每笔变动的原因（完成率/得分率、命中档位）；
2. **APP 内兑换**：选择虚拟权益（如看一集动画、玩网页小游戏、解锁皮肤）→ 即时扣减积分并解锁；
3. **向家长申请兑换**：选择现实权益（如周末去公园、一件小玩具）→ 提交申请 → 家长履约后扣减积分。

> 未解锁提示（中性措辞）：「本次未加分：必须完成项还没完成。」

### 4.7 孩子端设置 👦

- **模型切换**：在家长配置的模型池中选择当前学习模型；
- **语音设置**（VoiceSettings）：调整发音/语音相关偏好；
- 资料展示自动持久，新资料到达自动弹出。

## 五、通用说明

### 5.1 离线使用与多设备同步 🔧

- 认证后可**离线使用**；
- 孩子学习数据可**多设备云端同步**（按文件时间戳 last-write-wins 处理冲突）；
- 同步/备份在家长端「备份与恢复」管理。

### 5.2 数据安全与隔离 🔧

- 每个孩子的学习数据、进度、会话**严格按 childId 隔离**；
- 家长资料归属家长目录，孩子资料归属孩子目录，边界清晰；
- 孩子登录密码以加密形式保存在服务端（多设备登录一致），客户端本地仅保留离线回退缓存。

### 5.3 语音与评测配置 🔧

- 发音评测在**服务端**完成（凭证统一保存在服务端并加密，客户端录音后上传、拿回结果）；
- 家长在设置页配置评测服务商凭证并选择默认 provider（配置在服务端保存、多设备同步）；
- 腾讯智聆：句子模式中文 ≤30 字 / 英文 ≤60 词，段落模式中文 ≤120 字 / 英文 ≤300 词；
- 阿里声希：中文背诵/段落无字符硬上限，但录音时长须与文本大致匹配。

### 5.4 定时任务 🔧（Scheduler）

应用运行时的自动任务：

- **每日记录总结**：定时从会话提取学习总结，写入每日日志、进度、生活事件；
- **自动新建会话**：跨天或每天定点自动开新会话；
- 若到点应用未运行，下次启动时补执行。

## 六、常见问题 FAQ

**Q1：孩子忘记密码怎么办？**
A：家长在「孩子管理」中可重置孩子密码（密码仅家长可重置）。

**Q2：订阅到期后还能用吗？**
A：订阅到期前缓存在本地可离线使用；到期后需联网重新认证才能继续使用云端许可。

**Q3：为什么孩子不能手动勾选完成计划？**
A：无论是学习、考核还是生活计划，孩子端都**没有「标记完成」的勾选框**——所有计划的完成 / 未完成都由系统在满足条件时自动判定并打勾（学习 = 窗口内检测到学习发生；考核 = 在考核页提交场次；生活 = AI 据对话判定），以保证记录真实。家长可在「每日记录 / 对话回顾」中审计，并拥有修正权（撤销或标记取消）。

**Q4：考核时背诵题为什么看不到原文？**
A：为防止「看文朗读」，背诵/朗读题页面默认隐藏原文，孩子需凭记忆朗读；这是考核诚实性的设计。

**Q5：积分被扣分了，怎么回事？**
A：若「必须完成项」当天完成率未达标，会按负分档扣分；「加分项」永远不扣分。可在积分明细查看每笔变动原因。若加分项达标却没加分，通常是「必须完成项」未达门控阈值（待办 100% / 考核 90%）。

**Q6：英语课为什么有时候是中文？**
A：英语课默认全程英文；若开了「中英混合」兜底且孩子连续不理解，AI 会自动用中文解释，平时仍全英文沉浸式。

**Q7：家长改了配置，孩子端没变化？**
A：配置修改后会在约 2 分钟内同步到孩子端（下次进入或新开会话即生效）。若长时间未生效，请确认客户端已联网并处于登录状态。

**Q8：资料页打不开/没声音？**
A：请确认视频为 H.264 编码（不支持 HEVC/H.265）；资料须按主题目录 `media/` 结构存放；如仍异常，可在家长端重新上传资料到服务端真源。

**Q9：什么是「加分项」？为什么有时达标了却没加分？**
A：「加分项」是**孩子自己制定的计划**（学习 / 考核 / 生活计划孩子都可以自己定，见 §3.4），只加不扣。它加分有个前提：对应的「必须完成项」（家长制定的计划）完成率 / 得分率要达到门控阈值（待办 100% / 考核 90%）。若孩子自己的计划达标，但家长制定的计划没做完，本次就不加分，系统会提示「本次未加分：必须完成项还没完成」。
